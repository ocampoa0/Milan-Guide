# Milan Guide

A static Milan city guide that includes:

- A navigation bar for `Spots`, `Interactive map`, `Favourites`, and `Lang / Currency`
- Category index for `Attractions`, `Nightlife`, `Food`, `Shopping`, and `Instagramable`
- Spot cards with title, description, considerations, address, map link, representative image, and favourite star
- Clickable images that open a zoomable gallery modal
- A simple interactive map section with category filters and location cards
- Language and currency settings

## Files

- `index.html` — page structure and content sections
- `style.css` — layout, card styling, modal interactions, and responsive behavior
- `script.js` — dynamic rendering, page navigation, favourites, language/currency settings, and gallery interactions

## Usage

Open `index.html` in your browser to explore the Milan guide.
